# 中国历史朝代脉络全景

一张图看懂从史前传说到清末的中国朝代更迭。做这个的初衷很简单：让不懂历史的人也能快速建立起中国古代史的整体框架——哪个朝代在前、哪个在后、各自多长、出了哪些帝王和典故。

**在线预览：** [https://kiye922.github.io/history/](https://kiye922.github.io/history/)

## 功能

- **时间比例色块**：每个朝代的条长对应实际国祚，一眼看出谁长谁短
- **君主世系**：点击任意朝代展开，按顺序列出帝王、在位时间、主要事迹；庸君合并标注
- **重要制度与政策**：推恩令、科举制、三省六部制、行省制度等关键政治经济制度
- **经典著作**：每个朝代列出代表性典籍（《史记》《资治通鉴》《红楼梦》等），附作者与生卒年
- **典故与成语**：标注类型（政治/军事/经济/文化/典故）、在位时期与年份，点击展开解释
- **手机端适配**：底部弹窗式详情面板，左右滑动查看完整时间轴
- **公元元年参考线**：红色虚线标示公元前后分界，附前2000年、前1000年、后1000年灰色参考线

## 可信度标注

| 标签 | 含义 |
|------|------|
| 正史 | 见于《史记》《汉书》《三国志》《明史》等官修正史 |
| 古史传说 | 先秦或更早古史传说，无直接文字证据，多为后世追记 |
| 演义 | 《三国演义》等后世小说戏曲情节，非史实 |
| 存疑 | 正史记载模糊，或出土文献/现代史学有不同说法 |

## 技术栈

纯 HTML + CSS + JavaScript，单文件，零依赖，可离线使用。

## 数据说明

朝代起止年份采用通行历史教科书说法；先秦部分（夏、商、西周早期）因文献不足，年份为约数。君主在位时间据《史记》《资治通鉴》等整理，合并条目为史载简略或无重大事迹的帝王。著作作者生卒年据通行文献考证。
